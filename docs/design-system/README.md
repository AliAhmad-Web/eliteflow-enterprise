## Design Reference

- **Product aesthetic:** Premium enterprise dashboard (Linear, Notion, Stripe, Vercel)
- **Project reference:** EliteFlow — dark theme, purple accent, gold branding, glassmorphism
- **Default theme:** Dark
- **Supported themes:** Dark, Light
- **Dashboards:** Super Admin, Admin, Employee, Client
